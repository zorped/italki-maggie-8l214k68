Check 1

Nouns and be

  • Would you like some more chickens?

    Say it naturally

    Would you like some more chicken?

    As food, chicken is uncountable, like soup. To count it, use pieces: two more pieces of chicken. Chickens means the birds.

  • I have done many finished many practice in my high school.

    Say it naturally

    I did a lot of practice in high school.

    A finished time in the past: did. Practice, the activity, is uncountable: a lot of practice.

  • I need to add a… aware this when I use noun.

    Say it naturally

    I need to be aware of this when I use nouns.

    Aware is an adjective: be aware of something. After use, a general plural has no a: nouns.

  • Because I often confused.

    Say it naturally

    Because I'm often confused.

    Confused describes you, so it needs be: I'm confused. Often goes after be.

Check 2

Verbs and small words

  • It takes much time for him to finish the work.

    Say it naturally

    It takes a lot of time for him to finish the work.

    Both structures are correct: It takes him a lot of time to finish, and It takes a lot of time for him to finish. In a positive sentence, a lot of sounds more natural than much.

  • If you find I make mistakes, you can interrupt me.

    Say it naturally

    If you notice I make mistakes, you can interrupt me.

    Notice means see or hear something. Find usually means discover something you were looking for.

Rule · practice

If-sentences: four kinds

Your sentence about booking exhibitions was really an if-sentence. Here are the four kinds. Real situations first, then imagined ones.

Zero · habits and facts

if + present, present

  • If I have time, I usually book exhibitions.
  • If you heat water to 100°C, it boils.

First · real possibility

if + present, will or can

  • If this task moves to next month, I can help.
  • If I finish early, I'll call you.

Second · imagined now

if + past simple, would

  • If I had less work, I would help with the report.
  • If I had more time, I would learn more words.

Third · past that did not happen

if + had + participle, would have

  • If I had seen the email, I would have replied.
  • If I had known, I would have come.

One ruleDo not use will right after if. Say “If I have time…”, not “If I will have time…”. The same rule works after when.

Your sentences

  • If I have time, I will book many exhibitions.

    Say it naturally

    If I have time, I usually book exhibitions.

    This is something you usually do, so use the present in both parts. This is the zero conditional.

  • If this new task could move to next month, I think I will help at that time.

    Say it naturally

    If this task can be moved to next month, I can help then.

    A real possibility: if + present, then can or will. This is the first conditional.

Model · quiz

Because I had…

Your own example showed the pattern: the appointment came first, then you went. Use had + past participle for the earlier event.

  1. First, earlierI had an appointment with my colleague.
  2. Then, laterI went to the office this afternoon.
  3. Join themI went to the office because I had an appointment.

More examplesWe went to the park because we had planned it. I started studying hard because the exam dates had been announced.

Keep it simpleYou do not need had every time. Use it when it is important which event came first.

Compare · quiz

Takes time, spends time

You asked whether both sentence patterns are correct. They are.

It takes + person + time + to

the person comes first

  • It takes him a lot of time to finish the work.

It takes + time + for + person + to

the time comes first

  • It takes a lot of time for him to finish the work.
spend time + -ing: I spent a lot of time climbing the mountain. Consume means use up, like food or fuel. Time passes; you spend it.

Check yourself

  1. It     me an hour to get there.

  2. I     an hour reading the report.

  3. It takes a lot of time     him to finish.
